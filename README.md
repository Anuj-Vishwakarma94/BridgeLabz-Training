# BridgeLabz-Training

A comprehensive Java programming repository covering **Core Java fundamentals, Object-Oriented Programming, DSA, Collections, IO Streams, Java 8 Concepts, Java Design Patterns, Multithreading, DBMS, JDBC, and Refresher Training**.

---

## 📘 Training Overview

This repository documents my learning journey at **BridgeLabz**, spanning from **December 15, 2025** to present. The training is organized into structured branches covering different aspects of Java and backend development.

# 🎓 Learnings & Best Practices

* **Code Organization:** Following structured and maintainable project organization
* **Naming Conventions:** Using Camel Case, Pascal Case and meaningful names
* **Version Control:** Maintaining regular commits with descriptive messages
* **Problem Solving:** Breaking complex problems into smaller tasks
* **Documentation:** Maintaining clear and useful README files
