## 📚 Key Concepts Covered

### 🗄️ DBMS

- **Database Fundamentals:** Relational and Non-Relational Databases
- **SQL:** DDL and DML Operations
- **ER Diagrams:** Entities, Attributes, Relationships, Primary Keys, and Foreign Keys
- **Normalization:** 1NF, 2NF, 3NF, and BCNF
- **Indexing:** Single-column and Composite Indexes
- **Query Analysis:** Query optimization using `EXPLAIN`
- **Database Relationships:** One-to-Many Relationships and Foreign Key Constraints
- **SQL Joins:** INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN, SELF JOIN
- **Stored Procedures:** Creating procedures using `IN` and `OUT` parameters
- **Triggers:** BEFORE and AFTER Triggers
- **Transactions:** COMMIT, ROLLBACK, SAVEPOINT

### ☕ JDBC

- **JDBC Architecture**
- **JDBC Driver**
- **DriverManager**
- **Connection**
- **Statement**
- **PreparedStatement**
- **ResultSet**
- **CRUD Operations**
- **Maven Dependency Management**
- **Connecting Java with MySQL**
- **Exception Handling in JDBC**
